# 📊 Python Business Income Analysis

## 📌 Project Overview

This project is a simple Python program that analyzes daily business income.

The project was created as part of my journey toward becoming a practical
Data Analyst and Freelancer.

The program demonstrates how Python can be used to calculate business
performance metrics and identify patterns in daily income.

## 🎯 Objectives

The program calculates:

- Total income
- Average daily income
- Highest income day
- Lowest income day
- Number of good-income days
- Total income generated on good-income days

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional statements
- Basic data analysis

## 📊 Sample Data

The project currently uses sample daily income data:

| Day | Income |
|---|---:|
| Monday | €120 |
| Tuesday | €145 |
| Wednesday | €98 |
| Thursday | €160 |
| Friday | €175 |
| Saturday | €210 |
| Sunday | €130 |

## 📈 Results

Based on the sample data:

- **Total income:** €1,038
- **Average daily income:** €148.29
- **Highest income day:** Saturday (€210)
- **Lowest income day:** Wednesday (€98)
- **Good-income days:** 3
- **Income from good-income days:** €545
